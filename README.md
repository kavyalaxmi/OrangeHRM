# Playwright OrangeHRM Tests

End-to-end tests for the OrangeHRM demo application, written with Playwright
Test and TypeScript.

## Project setup

### Prerequisites

- Node.js 20 or later
- npm

### Install dependencies and browsers

From the project root, run:

```bash
npm ci
npx playwright install
```

The tests use the OrangeHRM demo URL and credentials configured in
`tests/data/test-data.ts` by default. You can override them with environment
variables:

| Variable | Purpose |
| --- | --- |
| `BASE_URL` | Application base URL |
| `TEST_USERNAME` | Login username |
| `TEST_PASSWORD` | Login password |
| `TEST_EMPLOYEE_SEARCH` | Text entered into the employee autocomplete |
| `TEST_EMPLOYEE_NAME` | New user employee name |
| `TEST_NEW_USERNAME` | Username for the user created by the test |
| `TEST_NEW_PASSWORD` | Password for the user created by the test |

Use environment variables for private credentials; do not commit secrets.

## Running the tests

Run the full test suite across configured browsers (Chromium, Firefox, and
WebKit):

```bash
npm test
```

Run Chromium only:

```bash
npm run test:chromium
```

The Chromium script runs headed. Other useful commands:

```bash
npm run test:headed
npm run test:ui
npm run report
```

`npm run report` opens the HTML report generated by a test run.

## Playwright version

This project uses Playwright Test **1.64.0** (`@playwright/test`).
